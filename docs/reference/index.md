# API reference

The API reference is generated from the docstrings in the source code, so it
always matches the installed version. Everything documented here can be
imported from the `contextsage` package:

```python
from contextsage import (
    DEFAULT_IDENTIFIER_PATTERNS,
    ConfigurationError,
    ContextSageError,
    IntelligentSummarizationMiddleware,
    RecoveryStatus,
    SummarizationEvent,
    ValidationStatus,
)
```

Modules and names that start with an underscore are internal and can change in
any release.

::: contextsage.errors
